## ✨ Fonctionnalités

- **Écran de chargement** façon jeu vidéo/app store (barre de progression animée + pourcentage).
- **Curseur personnalisé** en forme de viseur photo (coins qui encadrent le pointeur) avec traînée de comète.
- **Nom animé** : dégradé de couleur qui glisse en continu sur "MERDJI", lettres qui flottent.
- **Navbar dynamique** : indicateur qui glisse sous le lien survolé, bordure lumineuse défilante, logo réactif.
- **Reveal on scroll** : chaque section apparaît en fondu avec ses cartes en cascade.
- **Effet de frappe (typing)** sur l'option de formation.
- **Responsive** : structure adaptée mobile/desktop.

## 🗂️ Structure du site

Le portfolio respecte l'ossature imposée pour l'épreuve E5 :

1. **Accueil / Profil** — présentation, statut de recherche, liens de contact.
2. **Parcours / Formation** — cursus BTS SIO, option SISR.
3. **Compétences / Savoir-faire** — systèmes & réseaux, développement, outils, soft skills.
4. **Projets & Réalisations** — 3 projets réels déployés sur Vercel (Salon Élégance, Résidanat Révision, SMS Promo FR).
5. **Veille technologique** — sujet suivi et outils utilisés.
6. **Tableau de synthèse E5** — emplacement réservé pour le document officiel.

---

## 🛠️ Stack technique

| Fichier | Rôle |
|---|---|
| `index.html` | Structure de la page (sections, navigation, curseur, preloader) |
| `style.css` | Thème dark, accent vert menthe, toutes les animations |
| `script.js` | Logique JS : curseur, reveal on scroll, typing, compteurs, preloader |
| `en-travaux.html` | Page tampon pour les liens pas encore actifs (CV, LinkedIn) |

Aucun framework — **HTML/CSS/JavaScript vanilla**, déployé automatiquement sur **Vercel** à chaque push sur `main`.
