# Portfolio BTS SIO

Portfolio one-page inspiré du style dark/minimaliste "developer portfolio" (type abdullahalmonir.com),
adapté aux attendus de l'épreuve E5 du BTS SIO.

## Structure
- `index.html` — structure de la page (Hero, About, Skills, Projects, Veille techno, Contact)
- `style.css` — thème dark, accent vert menthe, cartes, stats animées
- `script.js` — animation des compteurs de stats

## À faire
Remplacer les placeholders ("Section en cours de rédaction") par le contenu réel :
nom, liens sociaux, CV, expériences, projets, compétences, veille technologique.

## Déploiement
Ce dépôt est connecté à un projet Vercel : chaque push sur `main` déclenche un déploiement automatique.
